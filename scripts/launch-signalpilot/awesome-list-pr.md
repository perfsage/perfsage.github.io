Add PerfSage SignalPilot — open-source K8s post-deploy RCA

## PR body

Adds PerfSage SignalPilot, an MIT-licensed tool for post-deploy Kubernetes root cause analysis. Correlates deploy diffs, K8s events, metrics-server, logs, and optional Prometheus/git into ranked findings with copy-paste kubectl fixes. Used as the prod RCA layer in the PerfSage OSS ladder (Reveal + SLO Reporter + SignalPilot).
